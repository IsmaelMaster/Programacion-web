Es elemento o atributo

  1. Width: Es atributo por que define el ancho de un elemento.
  2. td: Es elemento por que es un elemento de celda de tabla (table data).
  3. th Es elemento por que es un elemento de celda de encabezado de tabla (table header).
  4. name: Es atributo por que especifica el nombre de un elemento para identificacion en formularios.
  5. select: Es elemento por que es un elemento que crea un menu desplegable o lista de seleccion.
  6. type: Es atributo por que especifica el tipo de elemento (ejemplo: el tipo de input, tipo de lista)
