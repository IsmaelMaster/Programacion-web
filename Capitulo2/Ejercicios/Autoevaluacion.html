Ejercicios de autoevaluacion

2.1 Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por que.

  1. Una lista ordenada no puede anidarse dentro de una lista desordenada.
  2. El elemento br representa un salto de linea.
  3. Los hipervinculos se denotan mediante elementos link.
  4. La anchura de todas las celdas de datos en una tabla debe ser igual.
  5. Estamos limitados a un maximo de cinco vinculos internos por pagina.

2.2 Complete las siguientes oraciones:

  1. El elemento ______ inserta una regla horizontal.
  2. Para marcar un superindice se utiliza el elemento ______ y para marcar un subindice se utiliza el elemento ______.
  3. El elemento de encabezado menos importante es ______ y el elemento de encabezado mas importante es ______.
  4. El elemento ______ marca una linea desordenada.
  5. El elemento ______ marca un parrafo.
  6. El atributo ______ en un elemento input inserta un boton que, cuando se presiona, restablece el contenido del formulario.
  7. El elemento ______ marca una fila de una tabla.
  8. Los ______ se usan por lo general como caracteres de enmascarado en un cuadro de contraseña.

Ejercicios de autoevaluacion ya resueltos

2.1

  1. Falso. Una lista ordenada puede anidarse dentro de una lista desordenada y vicerversa.
  2. Verdadero.
  3. Falso. Los hipervinculos se denotan mediante elementos a.
  4. Falso. Puede especificar la anchura de cualquier columna, ya sea en pixeles o como un porcentaje de la anchura de la tabla.
  5. Falso. Puede tener un numero ilimitado de vinculos internos.

2.2

  1. El elemento hr inserta una regla horizontal.
  2. Para marcar un superindice se utiliza el elemento sup y para marcar un subindice se utiliza el elemento sub.
  3. El elemento de encabezado menos importante es h6 y el elemento de encabezado mas importante es h1.
  4. El elemento ul marca una linea desordenada.
  5. El elemento p marca un parrafo.
  6. El atributo type = "reset" en un elemento input inserta un boton que, cuando se presiona, restablece el contenido del formulario.
  7. El elemento tr marca una fila de una tabla.
  8. Los asterisco se usan por lo general como caracteres de enmascarado en un cuadro de contraseña.
