9.30 ¿Qué hace la siguiente función? // El parámetro b debe ser un entero positivo para evitar recursividad infinita. function misterio(a, b) { if (b == 1) return a; else return a + misterio(a, b - 1); }

Ejercicios ya resueltos

9.30

Respuesta: la función calcula a × b. Lo hace mediante sumas repetidas: suma a consigo mismo b veces, reduciendo b en 1 en cada llamada recursiva hasta llegar a 1.
