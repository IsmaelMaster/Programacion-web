9.5 Localice el error en cada uno de los siguientes segmentos de programa y explique cómo corregirlo: a) method g() { document.writeln("Dentro del método g"); } b) // Esta función debe devolver la suma de sus argumentos function suma(x, y) { var resultado; resultado = x + y; } c) function f(a) { document.writeln(a); };

Ejercicios ya resueltos

9.5

a) Error: method no es la palabra clave que se utiliza para comenzar la definición de una función. Corrección: cambiar method por function.

function g()
{
   document.writeln("Dentro de la función g");
}

b) Error: se supone que la función debe devolver un valor, pero no lo hace. Corrección: eliminar la variable resultado y colocar la instrucción return x + y; en la función, o agregar la instrucción return resultado; al final del cuerpo de la función.

function suma(x, y)
{
   return x + y;
}

c) Error: el punto y coma después del paréntesis derecho que encierra la lista de parámetros. Corrección: eliminar el punto y coma después del paréntesis derecho de la lista de parámetros.

function f(a)
{
   document.writeln(a);
}
