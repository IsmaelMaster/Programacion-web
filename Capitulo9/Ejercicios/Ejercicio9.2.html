9.2 Para el programa de la figura 9.13, indique el alcance (ya sea alcance global o de función) de cada uno de los siguientes elementos: a) la variable x. b) la variable y. c) la función cubo. d) la función salida.

9.2

Figura 9.13 | Ejercicio de alcance:

<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>Alcance</title>
<script>
   var x;

   function salida()
   {
      for (x = 1; x <= 10; x++)
         document.writeln("<p>" + cubo(x) + "</p>");
   } // fin de la función salida

   function cubo(y)
   {
      return y * y * y;
   } // fin de la función cubo

   window.addEventListener("load", salida, false);
</script>
</head>
<body></body>
</html>

a) Alcance global: x se declara fuera de cualquier función.

b) Alcance de función: y es el parámetro de la función cubo, así que sólo existe dentro de ella.

c) Alcance global: cubo se declara en el nivel superior del script.

d) Alcance global: salida también se declara en el nivel superior del script.
