Ejercicios de autoevaluacion

8.1 Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por que.

  1. El caso default es requerido en la instrucción de selección switch.
  2. La instrucción break es requerida en el último caso de una instrucción de selección switch.
  3. La expresión (x > y && a < b) es verdadera si x > y es verdadera, o si a < b es verdadera.
  4. Una expresión que contiene el operador || es verdadera si uno o ambos de sus operandos son verdaderos.

Ejercicios de autoevaluacion ya resueltos

8.1

  1. Falso. El caso default es opcional. Si no se necesita una acción predeterminada, entonces no hay necesidad de un caso default.
  2. Falso. La instrucción break se utiliza para salir de switch. La instrucción break no se requiere para el último caso en switch.
  3. Falso. Ambas expresiones relaciónales deben ser verdaderas para que toda la expresión sea verdadera cuando se utilice el operador &&.
  4. Verdadero.
