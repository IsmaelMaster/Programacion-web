6.19 Escriba una secuencia de comandos que obtenga del usuario el radio de un circulo y produzca texto de HTML5 que muestre el diametro, la circunferencia y el area de ese circulo. Use el valor constante 3.14159 para π. Use las tecnicas de GUI que se muestran en la figura 6.7. [Nota: Tambien puede usar la constante predefinida Math.PI para el valor de x. Esta constante es mas precisa que el valor 3.14159. El objeto Math esta definido por JavaScript y provee muchas herramientas matematicas comunes]. Usar las siguientes formulas (r es el radio): diametro = 2r, circunferencia = 2πr, area = πr 2 .
