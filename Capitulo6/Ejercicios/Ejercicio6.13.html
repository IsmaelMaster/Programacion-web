6.13 Dado y = ax 3 + 7, ¿Cuales de las siguientes instrucciones de JavaScript son correctas para esta ecuacion?

  1. y = a * x * x * x + 7;
  2. y = a * x * x * (x + 7);
  3. y = (a * x) * x * (x + 7);
  4. y = (a * x) * x * x + 7;
  5. y = a * (x * x * x) + 7;
  6. y = a * x * (x * x + 7);

  • La respuesta correcta es el numero: 1, 4, 5, 6
