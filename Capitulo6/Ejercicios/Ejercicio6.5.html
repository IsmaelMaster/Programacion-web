6.5 Escriba una instruccion (o comentario) para realizar cada una de las siguientes tareas.

  1. Indique que una secuencia de comandos calculara el producto de tres enteros [ Sugerencia: Use texto que ayude a documentar una secuencia de comandos].
  2. Declare las variables x, y, z y resultado.
  3. Declare las variables xVal, yVal y zVal.
  4. Pida al usuario que introduzca el primer valor, lea el valor del usuario y almacenelo en la variable xVal.
  5. Pida al usuario que introduzca el segundo valor, lea el valor del usuario y almacenelo en la variable yVal.
  6. Pida al usuario que introduzca el tercer valor, lea el valor del usuario y almacenelo en la variable zVal.
  7. Convierta la cadena xVal en un entero y almacene el resultado en la variable x.
  8. Convierta la cadena yVal en un entero y almacene el resultado en la variable y.
  9. Convierta la cadena zVal en un entero y almacene el resultado en la variable z.
  10. Calcule el producto de los tres enteros contenidos en lasvariables x, y y x, y asigne el resultado la variable resultado.
  11. Escriba una linea de texto de HTML5 que contenga la cadena "El producto es" seguido del valor de la variable resultado

6.5

  1. // Calcula el producto de tres enteros
  2. var x, y, z, resultado;
  3. var xVal, yVal, zVal;
  4. xVal = window.prompt("Escriba el primer entero: ", "0");
  5. yVal = window.prompt("Escriba el segundo entero: ", "0");
  6. zVal = window.prompt("Escriba el tercer entero: ", "0");
  7. x = parseInt(xVal);
  8. y = parseInt(yVal);
  9. z = parseInt(zVal);
  10. resultado = x * y * z;
  11. document.write("< h1> El producto es: " + resultado + "< /h1>");
