Ejercicio

3.4 Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por que.

  1. Los navegadores que despliegan el tipo input color como campo de texto requieren que el usuario introduzca el nombre de un color.
  2. Cuando un usuario introduce datos en un formulario y luego lo envia (por lo general, al hacer clic en el boton Enviar ), el navegador verifica de inmediato que los datos sean correctos.
  3. HTML5 puede validar si la direccion de correo electronico introducida por el usuario existente en realidad.
  4. Puede agregar required a cualquiera de los tipos input.
  5. Puede habilitar autocomplete solo para ciertos elementos input.
  6. El elemento time nos permite identificar una fecha, hora o ambas.
  7. El elemento caption proporciona una leyenda para la imagen en un elemento figure.
  8. El elemento details muestra una flecha que apunta a la derecha enseguida de un resumen o leyenda cuando el documento se despliega en un navegador. Al hacer clic en la flecha, esta apunta hacia abajo y revela el contenido del elemento summary.
  9. El elemento footer describe el contenido que por lo general aparece en la parte inferior del contenido o del elemento section.
  10. El elemento highlight nos permite resaltar texto.

3.4

  1. Falso. Cuando el navegador no soporta el tipo color, lo muestra como un campo de texto normal, pero no requiere especificamente que se introduzca el nombre de un color; el usuario podria escribir cualquier valor, aunque no sea valido. Ademas, los navegadores modernos suelen mostrar un selector de color en lugar de un campo de texto.
  2. Falso. La validacion del lado del cliente ocurre antes de enviar el formulario, no despues. Si los datos no son validos, el navegador impide el envio y muestra un mensaje de error.
  3. Falso. HTML5 solo puede validar que el formato del correo electronico sea correcto, pero no puede verificar si la direccion existe realmente. Eso requeriria una validacion del lado del servidor.
  4. Falso. El atributo required no se puede aplicar a todos los tipos input, por ejemplo no tiene efecto en input type = "hidden" , input type = "button" , input type = "submit" , input type = "reset" , ni en input type = "image"
  5. Verdadero.
  6. Verdadero.
  7. Falso. El elemento < caption > se usa para proporcionar un titulo a una tabla, no a una imagen. Para una imagen dentro de < figure >, se usa < figcaption >.
  8. Falso. El elemento < details > muestra la flecha y revela su contenido, pero el resumen o leyenda se coloca dentro del elemento < summary >, no al reves.
  9. Verdadero.
  10. Falso. No existe un elemento HTML llamado < highlight >. El elemento correcto para resaltar texto es < mark >.
