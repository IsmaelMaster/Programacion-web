Ejercicios de autoevaluacion

3.2 Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por que.

  1. Cualquier tipo input particular de formulario de HTML5 debe desplegarse de manera identica en todos los navegadores compatibles con HTML5.
  2. Cuando se coloca el enfoque en el campo de texto (es decir, si el cursor esta en el campo de texto), se envia el texto del atributo placeholder al servidor.
  3. No es necesario incluir el atributo autofocus en sus formularios
  4. Los nuevos tipos input de HTML5 tienen validacion automatica del lado del cliente, con lo cual se elimina la necesidad de agregar secuencias de comandos (script) complicadas a sus formularios para validar la entrada del usuario y se reduce la cantidad de datos invalidos que se envian.
  5. El tipo input range se valida automaticamente de manera intrinseca cuando el navegador lo despliega como un control deslizante, ya que el usuario no puede mover el control fuera de los limites del valor minimo o maximo.
  6. HTML5 cuenta con validacion automatica para el tipo input tel.
  7. Si el usuario introduce un URL con un formato inapropiado en un tipo input url, no se validara. HTML5 no valida si el URL introduciendo existe en realidad.
  8. El elemento nav muestra un menu desplegable de hipervinculos.
  9. El elemento header puede usarse solo una vez en una pagina.
  10. Los elementos nav pueden anidarse en un elemento aside.
  11. Podemos usar el elemento brk para evitar dividir palabras en lugares incorrecto.
